# Forme 기능 조사와 구현 추적

조사일: 2026-10-25. 공식 공개 도움말을 기준으로 기능을 분해하고 저장소 코드와 대조했다. 경쟁 제품을 로그인해서 전수 조작한 결과는 아니다. 문서에서 확인하지 못한 세부 동작은 추정으로 ‘지원’ 표시하지 않는다. 유료 플랜 가격·할당량은 이 문서의 비교 대상이 아니다.

기존의 ‘조건 구현’, ‘시트 구현’, ‘응답 구현’ 같은 큰 묶음은 실제 차이를 숨겼다. 아래 표는 **사용자가 끝까지 수행할 수 있는 작업 단위**로 판정한다. ‘기존’은 해당 범위의 코드가 있다는 뜻이며 전체 제품 동등성이나 대규모 운영 검증을 뜻하지 않는다.

## 중요한 차이

- 단순 제출 재시도 방지와 한 사람의 중복 응답 방지는 다른 기능이다.
- Apps Script 연결은 OAuth로 Google 계정과 시트를 고르는 UX와 다르다. 현재를 ‘Google Sheets 완전 연동’이라고 표시하지 않는다.
- AND/OR 비교는 추가했지만 중첩 그룹, 분기 점프, 조건부 필수, 계산은 별도 기능으로 남긴다.
- 답변 생성·검토는 Tally도 제공한다. AI 생성 자체를 Forme 고유 기능이라고 부르지 않는다.
- 전체 CSV와 화면의 검색/요약은 범위가 다르다. 검색/요약은 아직 불러온 응답 기준임을 UI에 명시한다.
- CSV의 현재 문항은 일반 열로, 삭제된 문항은 ‘이전 문항 답변 (JSON)’ 열에 원래 레이블과 함께 보존한다. 모든 과거 질문을 동적으로 펼친 와이드 포맷과는 다르다.
- 사용자 정의 오류 문구와 숫자/길이 제한이 있어도 Google의 정규식·문자열 규칙 전체를 지원한다고 볼 수 없다.
