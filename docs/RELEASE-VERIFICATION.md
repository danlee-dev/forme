## 한계

- DOM/SSR 검증이며, 새 브라우저 시각 검수는 실행하지 않았다.
- 1,007행은 대규모 부하·백만 행 내보내기 검증이 아니다. 스트리밍 실행 시간에는 플랫폼 한도가 있다. 장시간 내보내기는 백그라운드 작업이 필요하다.
- 화면 검색과 요약은 전체 서버 집계가 아닌 불러온 행 기준이다.
- Google OAuth, 실제 사용자 시트, 외부 메일·결제·팀 협업은 이번 검증 범위에 없다.
- API 키로 취소된 키는 이미 시작된 스트림을 소급 취소하지 않는다. 스트림은 요청 시 소유권 확인 후 최대 300초 범위에서 처리한다.
