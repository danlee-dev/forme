# Forme — 제품 기획 및 출시 기준

## 문제와 방향
좋은 질문, 브랜드에 맞는 표현, 응답 운영을 한 흐름으로 연결한다. 문서처럼 간단한 편집, 조용하고 읽기 쉬운 디자인, AI·API·MCP 연결을 제공한다. NEXT 전용이 아닌 범용 폼 제품이다.

## 사용자 흐름
- 제작자: 빈 폼/템플릿/AI → 문항 편집 → 디자인 → 미리보기 → 게시 → 공유.
- 응답자: 공개 폼 → 조건부 문항과 필수 표시 → 검증 → 제출 → 접수 확인.
- 운영자: 응답 표·검색 → CSV → 시트 연결·재시도.
- 개발자: 개인 API 키 발급·취소 → REST/MCP → 본인 폼 관리.

## UX와 데이터 기준
- 초안과 공개 버전은 분리하며 다시 게시하기 전 수정은 비공개다.
- 빈 상태에 다음 행동 제공. 가짜 지표 금지. 저장/실패/충돌 표시, 로컬 복구본 보존.
- 삭제 확인, 새 ID로 복제, 미리보기 제출은 저장하지 않음.
- 팔레트·배경·서체·모서리·커버·한 문항씩 모드.
- 키보드·포커스·오류 라벨·모바일·reduced-motion 지원.
- AI는 실제 모델 호출만 표시. 미연결 상태를 성공으로 위장하지 않음.
- 인증 Supabase Auth, 소유권 RLS. 공개 테이블은 게시 스냅샷만 포함.
- API 키 해시 저장. 연동 비밀 서버 암호화. 크기·타입 검증, 멱등 제출, 원자적 마감·정원 확인, CSV 수식 주입 방어.
- NEXT 미정 정보 유지, 과거 응답 미복제, 개인정보 안내 확정 전 예시는 접수 중단.

## 첫 릴리스 범위
개인 계정, 17종 블록, 조건부 문항, 편집/테마/게시/응답/CSV/버전 복구/JSON, AI 생성·문항 검토, Sheets Apps Script 연결, REST·MCP·플러그인 소스.
조직 공동편집, 결제, 파일 업로드, 사용자 도메인, OAuth 앱 심사, 과금, SSO는 후속 범위. 대규모 트래픽 검증에는 부하시험·봇 방어·관측·용량 계획이 추가로 필요하다.

## 검증
TypeScript·프로덕션 빌드·입력/조건/CSV 테스트, 브라우저 데스크톱·모바일, 인증 경계, 공개 배포, 게시 스냅샷과 실제 제출 확인. 외부 인증 전에는 연동 완료로 표시하지 않는다.
